# Fase 2 — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mapa vetorial próprio em escala real, começo do jogo sem ônibus com tutorial, tela Lista, save versionado, ônibus/logos novos, loja realista e viações rivais bloqueadas.

**Architecture:** Jogo Vite + TypeScript sem framework. Simulação pura em `src/sim` (estado imutável, ações devolvem `ActionResult`), store/loop em `src/game`, save validado em `src/save`, telas em `src/ui` (helper `h()` de `src/ui/dom.ts`), mapa Leaflet em `src/map`. Dados estáticos em `src/data` e (novo) `public/map`.

**Tech Stack:** TypeScript 7, Vite 8, Vitest 5 (jsdom nos testes de UI), Leaflet 1.9, Playwright (e2e), tsx (scripts).

**Spec:** `docs/superpowers/specs/2026-11-18-fase-2-design.md` (o design do MVP continua valendo: `docs/superpowers/specs/2026-11-12-minha-viacao-mvp-design.md`).

## Global Constraints

- Verificação de cada tarefa: `npm test` (todos passando), `npm run build` (tsc + vite) sem erro. Tarefas que mexem em telas também rodam `PW_CHANNEL=msedge npm run e2e`.
- Um commit por tarefa, mensagem em português no estilo `feat: ...`/`fix: ...`/`chore: ...`, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Não fazer push (o controlador faz).
- Toda cor nova vai para `src/ui/tokens.css` como variável CSS. O canvas do mapa lê as variáveis com `getComputedStyle`. Exceção já existente: cores fixas do desenho dos ônibus em `src/ui/busSvg.ts`.
- Sem dependência nova de npm. Se for inevitável, parar e relatar (motivo + licença).
- Texto do jogador (nomes de empresa/ônibus) só entra no DOM por `h()`/`textContent`, nunca `innerHTML`.
- Celular a partir de 360 px: nenhuma tela com rolagem horizontal da página (tabelas largas rolam dentro do próprio contêiner).
- Mudança no formato de `GameState` sobe `SAVE_VERSION`, acrescenta um passo em `src/save/migrate.ts` e testa com um save real da versão anterior em `src/save/fixtures/`.
- Nomes de modelos de ônibus são inventados; nada de nomes ou desenhos de fabricantes reais. Nomes reais de viações só em `src/data/rivals.ts`.
- Interface em português do Brasil, frases curtas, sem jargão.
